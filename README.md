# Predicting miRNA–disease associations via node-level attention graph auto-encoder

This directory contains source code and related datasets to run the AGAEMDA algorithm.

## Dependencies

This method has been tested under the following environment configuration:
- python 3.8.11
- pytorch 1.9.1
- pyg 2.0.3

## Run AGAEMD
```{python}
python agaemd_all_in_one.py
```
